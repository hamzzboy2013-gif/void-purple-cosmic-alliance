# VOID PURPLE: COSMIC ALLIANCE

A mobile open-world anime-inspired action RPG where players travel across cosmic worlds, battle legendary warriors, and recruit them as **Echoes**.

## Quick Start

1. Clone the repository
2. Open in Unity 2022.3 LTS or higher
3. Load the `MainScene` from `Assets/Scenes/`
4. Press Play

## Core Systems

- **Combat Engine** - Real-time anime-style action
- **Progression** - Player ranks, ally leveling, transformations
- **Ally System** - Recruit and upgrade warriors
- **Gear System** - Weapons, artifacts, relics
- **Raid System** - Multiplayer boss battles
- **Mobile Controls** - Optimized joystick + buttons
