# Gameplay Loop Documentation

## Main Loop Flow

```
┌──────────────────┐
│    EXPLORE       │  Travel worlds, find bosses, collect materials
└──────────┬───────┘
           ↓
┌──────────────────┐
│     FIGHT        │  Real-time combat with enemies
└──────────┬───────┘
           ↓
┌──────────────────┐
│   RECRUIT        │  Defeat elite warriors to unlock alliance
└──────────┬───────┘
           ↓
┌──────────────────┐
│   UPGRADE        │  Level up allies, unlock transformations
└──────────┬───────┘
           ↓
┌──────────────────┐
│     RAID         │  Multiplayer world bosses (4-player)
└──────────┬───────┘
           ↓
┌──────────────────┐
│    REPEAT        │  Unlock stronger worlds
└──────────────────┘
```

## Progression Gates

### Player Rank (Void Rank)
- F, E, D, C, B, A, S, SS, Cosmic
- Increases by: Quests, Bosses, Discovery, Raids

### Ally Progression
- Level (1-∞)
- Affinity (0-100)
- Star Rating (1-6)
- Forms: Base → Awakened → Void Corrupted

### World Progression
- 5 main worlds
- 5 levels per world
- Boss at world end
- Rewards increase with difficulty

## Reward Structure

### Experience Gains
- Enemy defeat: 50 XP (normal), 200 XP (elite)
- Boss defeat: 500+ XP
- Raid boss: 1000+ XP

### Loot Drops
- Common (Gray): Basic materials
- Rare (Blue): Weapon crafting
- Epic (Purple): Ally shards
- Legendary (Gold): Rare allies
- Mythic (Red): Elite warriors
- Voidborn (Dark Purple): Cosmic entities

## Monetization (Safe Model)

### Cosmetic-Only Purchases
- Character skins
- Battle pass (cosmetics only)
- Emotes and poses
- Mount skins
- Weapon visual effects

### NO Pay-to-Win
- Stats are grind-only
- Battle pass doesn't block content
- All allies available through gameplay
